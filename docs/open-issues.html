Open issues for linguists

1. Orthographic, not phonetic

Every v6 layer maps letter for letter. It preserves spelling, not sound. Bengali ব/ভ, Tamil's single stop letters, Urdu's vowel omission and the schwa rules of Hindi, Gujarati and Punjabi are not modelled.

2. Dialect-level phonetic mapping

The same letter is read differently by region and community. v6 ships one default table per script (v6/maps/*.csv). A dialect table would be a second CSV of the same shape plus a column for the sound; the generator would emit one fltr_* pair per dialect. Needed: a native-speaker phoneme table per dialect, with sources.

3. Pivot choices to confirm

Assamese ৰ to U+0931 and ৱ to U+0979; Tamil/Malayalam ழ ഴ to U+0934, ற റ to U+0931, ன ഩ to U+0929; Malayalam chillus to consonant+virama (forward only). U+0979 is not known to the zip 5 core.

4. Core limits seen (not fixed, by instruction)

Devanagari digits, several signs and a few letters do not survive Devanagari to Romenagri and back in zip 5; each script page lists them.

5. Research needed

Ground-truth corpora with native-reader judgement; loanword conventions; policies for conjuncts that exist in one script only; numerals and punctuation; a table for Sinhala and the tier C scripts.
