A script for Sanskrit and the Devanagari languages, written with characters that readers across the world already know, one visual unit for each Devanagari letter, and reversible to the byte. Base letters are Latin; length is a macron; retroflex is a dot below; aspiration is a raised h, as in the IPA; the diphthongs are ê and ô, so that no vowel sequence can be misread; vocalic r and l carry a ring below, which leaves ṛ for ड़. The letters are data (v7/ainagri/ainagri.csv), a proposal for the author's ruling.
