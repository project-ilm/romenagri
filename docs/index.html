Romenagri / ILM — Reversibility Report

Measured reversibility of the canonical kernel and corpus round trips. The canonical layer is the 84-token Romenagri grammar; ISCII and UTF-8 Devanagari are interchangeable compile-time substrates.

Kernel invariant — exhaustive enumeration

Each string fed as substrate input to acii2rmn, reversed via rmn2acii. exact=byte-identical; canonical=stable fixpoint; irreducible=neither; crash=no output. Run against both substrate libraries.

Corpus round trip — codepoint-classified (UTF-8 substrate)

The Unicode substrate consumes and emits UTF-8 directly. Core Devanagari letters and matras/signs are the kernel's domain; digits, danda/abbreviation punctuation and foreign codepoints are the documented frontier — flagged, not faked.

What this proves

Reversibility is a property of the Romenagri grammar, not of any byte encoding. The same parser over an ISCII substrate or a UTF-8 Devanagari substrate classifies identically on the exhaustive domain. Round-trip loss on real corpora is confined to non-letter codepoint classes (digits, punctuation, foreign script), which the UTF-8 substrate is positioned to carry where the 8-bit ISCII table cannot.
